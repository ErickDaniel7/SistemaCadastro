📖 Sobre o Projeto
Este projeto é um sistema desktop desenvolvido em Java Swing, com o objetivo de gerenciar cadastros de uma empresa fictícia. O sistema permite cadastrar clientes, funcionários, fornecedores, produtos e vendas, garantindo a persistência dos dados por meio de arquivos TXT.

#

✅ Tecnologias Utilizadas:

Java (Swing, JTable)

Manipulação de Arquivos TXT

Máscaras de Campos (CPF, CNPJ, Telefone, Datas)
